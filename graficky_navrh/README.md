# Grafický návrh Kafka Monster

Závazná původní frontendová předloha pro šablonu PrestaShopu.

- `index.html`: homepage a katalogové stránky.
- `product.html`, `product.css`, `product.js`: detail produktu.
- `app.js`, `theme-system.js`: interakce a klientský výběr barev.
- `catalog-data.js`, `catalog-live.generated.js`, `catalog-model.ts`: katalog předlohy.
- `HOMEPAGE-ARCHITECTURE.md`: popis původní homepage.
- `scripts/`: kontrola detailu a generování katalogu předlohy.

Sdílená grafika zůstává v `../assets/`. Aktuální pravidla převodu a referenční snímky jsou v `../design/`. Skutečný obchod se upravuje v `../prestashop/themes/kafka/`.

Předlohu otevři přes `start.bat` v kořeni projektu: homepage na http://localhost:4173/ a detail na http://localhost:4173/product.html. Tyto adresy zůstávají stejné.
